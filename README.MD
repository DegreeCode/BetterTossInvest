# BetterTossInvest

BetterTossInvest는 토스증권 웹 화면에 호가선, 국내주식 중간호가 개선, 초 단위 차트, 빠른 실시간 시세 반영 기능을 추가하는 유저스크립트입니다.

- 현재 버전: `1.3.0`
- 적용 주소: `https://www.tossinvest.com/*`, `https://tossinvest.com/*`
- 실행 시점: `document-start`
- 유저스크립트 권한: `@grant none`
- 외부 라이브러리: 없음

> 이 프로젝트는 토스증권의 공식 기능이나 공식 제품이 아닙니다. 화면에 표시되는 가격과 호가는 참고용으로 사용하고, 주문 전에는 토스증권의 원래 주문 화면에서 가격과 수량을 다시 확인하세요.

## 주요 기능

### 매수·매도 호가선

TradingView 차트에 현재 매수 1호가와 매도 1호가를 실시간 선으로 표시합니다.

- 토스증권이 이미 수신한 호가 및 체결 메시지를 사용합니다.
- 국내 종목 코드와 해외 종목 코드 형식을 구분해 처리합니다.
- 종목별 최신 호가를 메모리에 보관하며 최대 보관 종목 수를 설정할 수 있습니다.
- TradingView 내부의 네이티브 Bid/Ask 표시 기능을 사용합니다.

### 국내주식 중간호가 개선

국내주식 주문 화면에서 KRX·NXT 중간호가와 우세 수량을 보기 쉽게 표시합니다.

- 매도호가와 매수호가 사이에 중간호가 행 추가
- 수량이 없는 중간호가도 표시
- 중간호가 행 높이 축소
- 오른쪽 기준정보에 우세 수량 표시
- 오른쪽 기준정보의 기존 중간호가 행 숨김

각 항목은 설정에서 따로 켜거나 끌 수 있습니다.

### 초 단위 차트

1~60초 범위의 초봉 프리셋을 차트에 추가합니다. 기본값은 `1, 3, 5, 10, 15, 30, 60초`입니다.

- 토스증권이 이미 요청한 체결 내역 응답과 기존 실시간 메시지를 수집합니다.
- 수집한 틱을 브라우저 메모리에서 OHLCV 초봉으로 집계합니다.
- 초봉 조회 시 토스증권의 원래 과거 캔들 `getBars`를 호출하지 않습니다.
- 종목별 체결 데이터 수와 동시 보관 종목 수를 제한해 메모리 사용량을 관리합니다.
- 이 기능은 기본적으로 꺼져 있습니다.

초봉은 스크립트 실행 이후 브라우저가 확보한 데이터만으로 생성되므로, 일반 분봉처럼 긴 과거 구간이 항상 제공되지는 않습니다.

### 빠른 실시간 시세 반영

토스증권 화면의 실시간 메시지 처리 간격을 조정합니다.

- 원래 100ms 또는 200ms 단위로 묶이던 화면 갱신을 설정한 간격으로 처리합니다.
- 기본 갱신 간격은 `16ms`입니다.
- WebSocket 수신 주기나 서버 전송 주기를 바꾸는 기능이 아니라, 이미 수신한 메시지를 화면에 반영하는 간격을 바꾸는 기능입니다.
- 간격이 짧을수록 CPU 사용량과 렌더링 부하가 늘 수 있습니다.

## 설치

1. 브라우저에 Tampermonkey 또는 호환 유저스크립트 관리자를 설치합니다.
2. 새 유저스크립트를 만듭니다.
3. [BetterTossInvest.js](./BetterTossInvest.js)의 전체 내용을 붙여 넣고 저장합니다.
4. 토스증권 웹 페이지를 새로 열거나 새로고침합니다.

스크립트는 최상위 토스증권 페이지에서만 실행되며 하위 프레임에서는 실행되지 않습니다.

## 설정

토스증권 설정 모달을 연 뒤 사이드바의 **BetterTossInvest** 항목을 선택하면 설정 화면이 열립니다. 설정을 저장하거나 기본값으로 초기화하면 페이지가 새로고침된 뒤 변경 내용이 적용됩니다.

설정은 브라우저 `localStorage`의 다음 키에 저장됩니다.

```text
better-toss-invest-settings-v1-release
```

## 네트워크 및 개인정보 처리

현재 `BetterTossInvest.js`를 정적 검사한 결과는 다음과 같습니다.

### 하지 않는 것

- 별도 WebSocket 연결을 만들지 않습니다.
- `WebSocket.send()` 또는 SharedWorker의 `port.postMessage()`로 별도 메시지를 보내지 않습니다.
- 외부 수집 서버나 분석 서버로 데이터를 전송하지 않습니다.
- 주문, 계좌, 인증 또는 사용자 정보를 변경하는 API를 호출하지 않습니다.
- `POST`, `PUT`, `PATCH`, `DELETE`, `sendBeacon` 요청을 직접 만들지 않습니다.
- 외부 `@require`, `@resource`, `@connect` 리소스를 사용하지 않습니다.
- 쿠키, 세션 스토리지, IndexedDB를 직접 읽거나 기록하지 않습니다.

### 사용하는 기존 통신

- 페이지의 기존 `fetch`를 한 번 그대로 호출하고, 체결 내역 응답의 복사본을 브라우저에서 분석합니다. 응답 복사는 추가 네트워크 요청을 만들지 않습니다.
- 토스증권이 생성하는 기존 SharedWorker의 수신 메시지에 리스너를 추가합니다.
- 실시간 갱신 기능은 토스증권 화면이 원래 요청한 구독을 기존 연결로 전달합니다. 별도 종목이나 별도 destination을 추가로 구독하지 않습니다.
- 호가선과 중간호가 기능은 기존 호가·체결 메시지를 읽어 화면에 반영합니다.

### 조건부로 발생할 수 있는 추가 요청

호가선 기능은 TradingView 내부 webpack 청크 `2650`을 동적으로 로드합니다. 해당 청크가 아직 로드되지 않았거나 브라우저 캐시에 없으면 TradingView 또는 토스증권이 사용하는 정적 자산 서버로 GET 요청이 발생할 수 있습니다. 요청 주소는 스크립트에 하드코딩되어 있지 않고 TradingView webpack 런타임이 결정합니다.

또한 설정을 저장하거나 초기화하면 `location.reload()`가 실행되므로, 페이지를 다시 여는 과정에서 토스증권의 일반 요청이 다시 발생합니다.

따라서 서버 데이터를 변경하거나 외부로 정보를 전송하는 스크립트는 아니지만, 엄밀한 의미의 **추가 네트워크 요청 0건**을 보장하지는 않습니다. 동적 청크 요청까지 피하려면 매수·매도 호가선 기능을 끄세요.

## 동작 방식과 주의사항

이 스크립트는 토스증권의 DOM과 브라우저 런타임을 클라이언트에서 확장합니다. 주요 구현 방식은 다음과 같습니다.

- 페이지의 `fetch`와 `SharedWorker`를 감싸 기존 응답 및 수신 메시지 관찰
- Next.js 및 TradingView webpack 런타임 후킹
- TradingView datafeed와 widget 생성자 확장
- DOM 요소 및 스타일 추가
- `MutationObserver`를 이용한 SPA 화면 변경 감지

토스증권의 내부 DOM 구조, webpack 모듈 또는 TradingView 구현이 변경되면 일부 기능이 동작하지 않거나 화면 오류가 발생할 수 있습니다. 문제가 생기면 다음 순서로 확인하세요.

1. BetterTossInvest 설정에서 문제가 의심되는 기능을 끕니다.
2. 페이지를 새로고침합니다.
3. 렉이나 CPU 사용량이 높다면 실시간 갱신 간격을 늘리거나 해당 기능을 끕니다.
4. 차트 문제가 있다면 초 단위 차트와 매수·매도 호가선을 각각 끄고 확인합니다.
5. 스크립트를 완전히 비활성화해 토스증권 원래 화면에서 같은 문제가 발생하는지 확인합니다.

## 면책 고지

BetterTossInvest는 토스증권 또는 비바리퍼블리카가 개발·제공·보증하는 공식 소프트웨어가 아니며, 해당 회사들과 제휴하거나 승인받은 프로젝트가 아닙니다. 이 스크립트에서 제공하는 기능과 정보는 사용 편의를 위한 참고 자료일 뿐이며 투자 자문, 투자 권유, 매매 신호 또는 수익 보장을 의미하지 않습니다.

- 스크립트가 표시하는 가격, 호가, 거래량, 차트 및 기타 정보에는 지연, 누락, 계산 오차 또는 표시 오류가 발생할 수 있습니다.
- 실제 주문을 제출하기 전에는 반드시 토스증권의 공식 주문 화면에서 종목, 주문 방향, 가격, 수량 및 계좌 정보를 직접 확인해야 합니다.
- 토스증권 웹사이트의 업데이트나 내부 구조 변경으로 일부 기능이 예고 없이 오작동하거나 중단될 수 있습니다.
- 스크립트 사용 여부와 사용 방법, 관련 서비스의 이용약관 및 적용 법령 준수에 대한 책임은 사용자에게 있습니다.
- 로그인 세션이나 금융정보를 다루는 페이지에서 실행되는 유저스크립트의 특성상, 사용자는 설치 및 업데이트 전에 소스 코드를 직접 검토해야 합니다.
- 이 소프트웨어는 상품성, 특정 목적 적합성, 정확성, 안정성 및 중단 없는 동작에 대한 명시적·묵시적 보증 없이 현재 상태 그대로 제공됩니다.
- 법률상 허용되는 범위에서 개발자와 배포자는 이 스크립트의 설치·사용·오작동·중단 또는 표시 정보에 대한 의존으로 발생한 거래 손실, 기회비용, 데이터 손실, 계정 문제 및 기타 직·간접 손해에 책임을 지지 않습니다.

이 스크립트를 설치하거나 계속 사용하면 위 위험과 제한사항을 이해하고 본인의 판단과 책임으로 사용하는 것에 동의한 것으로 간주합니다. 위 문구는 적용 법률에 따라 제한될 수 있으며 법률 자문을 대신하지 않습니다.
