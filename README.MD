# BetterTossInvest

토스증권 웹에서 차트를 더 편하게 보고 호가 정보를 확인할 수 있도록 돕는 Tampermonkey 스크립트입니다.

**버전 1.5.0** · PC 웹용 · [토스증권](https://www.tossinvest.com)에서 사용

## 어떤 기능이 있나요?

| 기능 | 사용 방법 | 기본 설정 |
| --- | --- | --- |
| 매수·매도 호가선 | 종목 차트에서 현재 매수 1호가와 매도 1호가를 선으로 확인합니다. | 켜짐 |
| 국내주식 중간호가 개선 | KRX·NXT 중간호가와 우세 수량을 보기 쉽게 표시합니다. 표시 위치와 행 높이도 선택할 수 있습니다. | 켜짐 |
| 할로우 캔들 복원 | 차트 모양에서 **할로우 캔들**을 선택해 원래의 채움 규칙으로 봅니다. | 켜짐 |
| 지수 차트 조작 | 지수 상세 차트에서 이동, 확대·축소, 가격축 조절, 차트 모양 선택을 사용합니다. | 켜짐 |
| 초 단위 차트 | **초봉** 메뉴에서 1~60초 사이의 차트 주기를 선택합니다. | 꺼짐 |
| 실시간 시세 갱신 | 수신한 시세를 화면에 반영하는 간격을 조절합니다. | 켜짐 |

## 설치하기

1. 브라우저에 **Tampermonkey** 또는 호환 유저스크립트 관리자를 설치합니다.
2. Tampermonkey에서 **새 스크립트 만들기**를 엽니다.
3. 기본으로 들어 있는 내용을 지우고, 이 저장소의 **BetterTossInvest.js** 전체 내용을 붙여 넣습니다.
4. 저장한 뒤 토스증권 페이지를 새로고침합니다.

배포 파일이 `BetterTossInvest.user.js`라면 Tampermonkey의 가져오기 기능으로 설치해도 됩니다. 두 파일의 스크립트 내용은 같습니다.

### 이전 버전에서 업데이트하기

Tampermonkey에서 기존 **BetterTossInvest**를 열고 새 버전의 전체 내용으로 교체한 뒤 저장하세요. 기존 설정은 유지되며 새 기능은 위 표의 기본값으로 추가됩니다.

별도로 설치했던 **Toss Indicator Chart Unlock / 토스증권 인디케이터 차트 잠금 해제**는 꺼 주세요. 이제 BetterTossInvest의 **지수 차트 조작**에 포함되어 있습니다. 같은 기능의 스크립트를 여러 개 켜 두면 중복 적용될 수 있습니다.

## 설정 바꾸기

토스증권의 **설정**을 연 다음 왼쪽 메뉴에서 **BetterTossInvest**를 선택합니다.

- **사용할 기능**에서 원하는 기능을 켜거나 끕니다.
- **저장**을 누르면 페이지가 새로고침되며 변경 사항이 적용됩니다.
- **기본값으로 초기화**를 누르면 BetterTossInvest 설정이 초기화되고 페이지가 새로고침됩니다.
- 설정 항목의 이름을 클릭하면 자세한 설명을 볼 수 있습니다.

설정은 현재 브라우저에 저장됩니다. 다른 브라우저나 프로필에는 별도로 설정해야 합니다.

## 차트 기능 사용하기

### 할로우 캔들

차트 모양 메뉴의 **투명캔들**이 **할로우 캔들**로 바뀝니다. 해당 유형을 선택하면 다음 규칙으로 표시됩니다.

- 종가가 시가보다 낮으면 몸통을 채웁니다.
- 종가가 시가 이상이면 몸통을 비웁니다.
- 상승·하락 색상은 이전 봉의 종가와 비교해 정해집니다. 토스에서 선택한 색상은 유지됩니다.

기능을 켜도 현재 보고 있는 차트 유형은 자동으로 바뀌지 않습니다.

### 지수 차트

지수 상세 페이지의 차트에서 다음 조작을 사용할 수 있습니다.

- 차트를 드래그해 좌우로 이동
- 마우스 휠로 확대·축소
- 가격축을 드래그해 세로 배율 조절
- 차트 상단의 모양 선택 메뉴로 캔들·라인 등 선택

이 기능은 지수 상세 페이지에 적용됩니다. 상단에는 차트 모양 선택에 필요한 메뉴를 표시하며, 초봉 기능과 함께 켜도 사용할 수 있습니다.

### 초 단위 차트

설정에서 **초 단위 차트**를 켜고 저장한 뒤, 차트의 **초봉** 메뉴에서 원하는 주기를 고르세요. 기본 목록은 **1, 3, 5, 10, 15, 30, 60초**입니다.

초봉은 페이지에서 확보한 실시간 시세와 체결 내역으로 만들어집니다. 처음 열었을 때는 표시할 데이터가 적거나 없을 수 있으며, 일반 분봉처럼 긴 과거 기록이 제공되지는 않습니다. 페이지를 새로고침하면 메모리에 모은 데이터도 초기화됩니다.

## 세부 설정

### 국내주식 중간호가

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| 호가창 안에 중간호가 표시 | 꺼짐 | 매도호가와 매수호가 사이에 중간호가 행을 추가합니다. |
| 수량 없이도 항상 표시 | 꺼짐 | 수량이 없어도 유효한 중간호가 가격을 표시합니다. |
| 중간호가 행 높이 줄이기 | 꺼짐 | 추가한 중간호가 행을 작게 표시합니다. |
| 오른쪽 정보에 수량 표시 | 켜짐 | 오른쪽 기준정보에 우세 수량을 표시합니다. |
| 오른쪽 중간호가 숨기기 | 꺼짐 | 오른쪽의 기존 중간호가 정보를 숨깁니다. |

### 성능과 데이터 보관

| 설정 | 기본값 | 설정 범위 |
| --- | --- | --- |
| 호가선 최대 보관 종목 수 | 1,000개 | 10~10,000개 |
| 초봉 시간 단위 | 1, 3, 5, 10, 15, 30, 60초 | 1~60초, 쉼표로 구분 |
| 초봉 종목별 최대 체결 내역 수 | 50,000개 | 1,000~200,000개 |
| 초봉 최대 보관 종목 수 | 6개 | 1~30개 |
| 화면 갱신 간격 | 16ms | 8~1,000ms |

화면 갱신 간격이 작을수록 반영은 빨라지지만 CPU 사용량이 늘 수 있습니다. 버벅임이 있다면 간격을 늘리거나 해당 기능을 꺼 보세요. 이 설정은 시세 서버의 전송 속도를 바꾸지는 않습니다.

## 잘 안 될 때

- **기능이나 설정 메뉴가 안 보여요:** Tampermonkey에서 스크립트가 켜져 있는지 확인하고 토스증권을 새로고침하세요. 스크립트 관리자에 실행 권한 안내가 표시되면 해당 안내도 확인하세요.
- **할로우 캔들이 안 보여요:** 복원 기능을 켠 뒤 차트 모양에서 할로우 캔들을 선택하세요. 사이트 업데이트로 메뉴 이름 변경이 적용되지 않으면 투명캔들로 표시될 수 있습니다.
- **초봉이 비어 있어요:** 페이지를 열어 둔 채 새 시세가 들어올 때까지 기다려 보세요. 새로고침 직후에는 모인 데이터가 적습니다.
- **차트가 느리거나 이상해요:** 문제가 생긴 기능을 하나씩 끄고 저장해 확인하세요. 별도로 설치한 차트 관련 스크립트가 있다면 함께 점검하세요.
- **원래 화면으로 돌아가고 싶어요:** Tampermonkey에서 BetterTossInvest를 끄고 페이지를 새로고침하세요.

문제를 제보할 때는 스크립트 버전, 브라우저, 문제가 발생한 페이지 주소, 켜 둔 기능, 재현 순서를 함께 알려 주세요. 화면을 첨부한다면 계좌번호·잔고 등 개인 정보는 가려 주세요.

## 알아두세요

BetterTossInvest는 토스증권의 공식 제품이 아닌 개인 편의용 도구입니다. 주문을 자동으로 실행하지 않으며, 외부 수집 서버로 정보를 보내지 않습니다. 호가선 기능은 필요할 때 차트 표시용 파일을 추가로 불러올 수 있습니다.

토스증권 사이트가 바뀌면 일부 기능이 작동하지 않을 수 있습니다. 표시되는 시세에는 지연이나 오류가 있을 수 있으므로 주문 전 가격과 수량은 토스증권의 원래 주문 화면에서 확인하세요.
